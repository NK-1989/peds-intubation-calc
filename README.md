# 小児 緊急気管挿管 薬剤・気管チューブ計算

体重（kg）を入れると、気管チューブのサイズと、挿管時の薬剤・拮抗薬・アドレナリンの投与量（mL）と希釈方法を表示します。院内の「小児 緊急気管挿管フロー」の付属ツール（案）です。

公開URL: https://nk-1989.github.io/peds-intubation-calc/

## 表示する内容

| 区分 | 薬剤 | 1回量 | 投与液 |
|---|---|---|---|
| 鎮静 | ミダゾラム | 0.1 mg/kg | 10mg/2mL＋5%糖液 8mL（1 mg/mL） |
| 拮抗 | フルマゼニル | 0.01 mg/kg（上限 0.2 mg） | 原液 0.1 mg/mL |
| 鎮痛 | フェンタニル | 1 μg/kg | 100μg/2mL＋5%糖液 8mL（10 μg/mL） |
| 拮抗 | ナロキソン | 3 μg/kg | 0.2mg/1mL＋5%糖液 9mL（20 μg/mL） |
| 筋弛緩 | ロクロニウム | 1 mg/kg | 原液 10 mg/mL |
| 拮抗 | スガマデクス（ブリディオン） | 16 mg/kg | 原液 100 mg/mL |
| 蘇生量 | 10倍アドレナリン | 10 μg/kg | 1mg/1mL＋5%糖液 9mL（100 μg/mL） |
| 昇圧量 | 100倍アドレナリン | 1 μg/kg | 10倍アドレナリン 1mL＋5%糖液 9mL（10 μg/mL） |

気管チューブは PALS（AHA）表56 の体重区分（3〜36kg）によります。

## 注意

- 計算結果は目安です。投与前に体重・濃度・mL をダブルチェックしてください。
- 入力した体重は端末内で計算するだけで、保存も送信もしません。

## 開発

ビルド不要の HTML/JS です。計算ロジックは `calc.js`、テストは `node tests/calc.test.js`。
